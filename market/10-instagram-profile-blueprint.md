## 4. Story Highlights (4 Essential Trays)

Named for the exact questions a prospective user asks:

1. **`Start Here`**
   - 60-second guided onboarding loop preview.
   - Core cycle: Learn → Practice → Journal → Insight.
   - How to get the app on iOS.
2. **`Exercises`**
   - Microlearning walk-throughs: Thought Catcher, PMR (Progressive Muscle Relaxation), Fear Ladder, Gratitude Reframe.
3. **`Science`**
   - Plain-English CBT principles: cognitive distortions, thought reframing, habit formation.
4. **`Happi`**
   - Mascot backstory, situational animations, streak celebration clips.
