# Codebase context — shared course exercise system

- Happy is Expo Router React Native app for calm CBT and psychoeducation.
- Existing registry already supports choice, true/false, matching, ordering, fill-in, scenario, guided response, free text, ratings, and cards.
- Current course runtime allows wrong answers to advance, hides authored explanations, discards responses, and has no concept mastery or delayed review.
- Shared system must use simple language, calm feedback, optional private reflection, bounded telemetry, and no diagnostic or treatment claims.
- Same interaction formats must work across every course. Course authors may change prompts, examples, answer keys, and scenario content only.
- No dependency, package-manager, or course-content changes belong in this decision.
