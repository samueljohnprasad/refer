## 2. In-App Rendering Rules
- **Component**: Always render via [`HappiMascot.tsx`](file:///Users/samuelprasad/Desktop/happy/journals/src/screens/OnboardingScreen/components/HappiMascot.tsx).
- **Default Sizes**:
  - Hero / Onboarding: `size={160}` or `size={180}`
  - Standard Card / Step: `size={120}` to `size={140}`
  - Compact / Modal / Nudge: `size={80}` to `size={100}`
- **Floating Motion**: The subtle $\pm 4\text{px}$ sinusoidal floating animation is enabled by default (`animate={true}`). Disable (`animate={false}`) when rendering in static table cells or small badges.
