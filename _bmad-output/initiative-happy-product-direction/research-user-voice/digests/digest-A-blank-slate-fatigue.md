## Friction Patterns

### 1. 🧱 The Blank Canvas Wall
Full cognitive burden lands on user. App shows empty text box + blinking cursor.
**Signals:** "staring at a blank white screen", "cursor blinking at me", "nothing hits my mind"

### 2. 🏔️ The Performance Trap
Users feel entry must be profound, articulate, "worth writing." Self-care becomes homework.
**Signals:** "feel stupid", "we need writing to be profound", "felt like a second job"

### 3. 🌀 The Overwhelm Paradox
When anxiety is highest → too much to say → can't choose where to start → complete freeze.
**Signals:** "too much thoughts to write down that you end up not journalling at all"

### 4. 💀 The Shame Spiral of Abandonment
Miss 2 days → open app → see empty/broken state → guilt → close immediately → repeat.
**Signals:** "You missed 3 days!" as failure trigger, "excited for 3 days, forget it exists by day 7"

### 5. 🤖 CBT Jargon / Clinical Homework Overload
Multi-step forms thrown at users already overwhelmed. "cognitive distortions", "automatic thoughts" = alien language.
**Signals:** "filling out a digital spreadsheet", "clinical taxonomy feels exhausting"

### 6. 🔔 Notification Guilt
Generic "Time to journal!" feels like accountability, not care. Missed notifications = perceived failure.
**Research:** JMIR confirms context-unaware reminders increase app deletion rates.

### 7. 🎭 Robotic Scripted Interactions
Pre-scripted CBT paths force narrow choices. Emotional state doesn't fit script → users feel unseen and stupid.
**Signals:** "I don't even know what to say to this", "silly, patronized, downright stupid talking to a screen"

### 8. 🧾 Paywall Mid-Onboarding
User opens to explore → immediate subscription wall before any felt value → distrust before habit forms.
**Signals:** "gates too many features behind aggressive subscription pop-ups"

## Workarounds Users Invented

| Workaround | Description | Source |
|---|---|---|
| **Write the literal truth** | Type "I have no idea what to write. My brain is blank." — breaks the seal | r/Anxiety |
| **The Ugly App trick** | Switch to Apple Notes deliberately — removes "official journal" performance pressure | r/ADHD |
| **Voice rant → transcribe** | 60-second voice rant, optionally transcribe. Bypasses typing block entirely. | r/ADHD |
| **Interstitial journaling** | Write timestamp + 1 sentence whenever it strikes. No narrative required. | r/ADHD |
| **The Weather Report** | Start with literal weather outside. Zero cognitive load opener. | r/Anxiety |
| **Brain dump list** | Bullet fragments, not prose — "1. Neck hurts, 2. Need groceries, 3. Annoyed about email" | r/Journaling |
| **Scrap Paper trick** | Write on random paper — removes permanence anxiety | r/Anxiety |
| **One-sentence permission** | Goal: 3 words or 1 sentence. Close after that if needed. Paradoxically leads to more. | r/ADHD |
| **Delete the app entirely** | Guilt about not using the app → relief after deletion. Remove the shame source. | r/Anxiety |

## Research Evidence

- **30–50% of mental health app users abandon after 1–2 sessions** (JMIR systematic reviews, NIH meta-analyses)
- **Peak abandonment: days 1–10.** Download spikes during acute distress; habit fails to form.
- **"Download-to-Dust" phenomenon**: Apps downloaded late at night during stress, rarely opened again.
- **Context-unaware push notifications → deletion.** Leading deletion trigger.
- **Structured/scaffolded prompts dramatically reduce cognitive friction** vs. open-ended blank fields.

## Design Implications for Happy

| User pain | Happy design response |
|---|---|
| Blank canvas → freeze | NEVER show blank text box first. Lead with prompt, mood tap, or sentence starter. |
| Performance pressure | Frame entries as "messy drafts". Copy: "Nothing has to be perfect here." |
| CBT jargon overwhelm | Plain language only on first interaction. Show concepts, not labels. |
| Shame from missing days | No "you missed X days" copy. Normalize gaps explicitly. |
| Overwhelm → avoidance | Offer "I'm too overwhelmed to think right now" as a valid entry mode. |
| Voice over typing | Voice-first input option for first entry — lowest friction start possible. |
| Paywall in onboarding | Paywall comes after first useful loop, never before. |
